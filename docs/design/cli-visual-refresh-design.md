# Codepilot CLI 视觉改版设计

## 目标

在不引入全屏 TUI 框架、不改变 Runtime/Session/工具协议的前提下，提升交互模式的视觉层级、信息密度和可读性。整体风格参考 Codex CLI 的紧凑信息流和 Claude Code 的状态提示，但保留 Codepilot 自己的名称、色彩和学习项目定位。

## 设计原则

- 让用户优先看到“当前在做什么”，配置元数据退居次要层级。
- 终端输出保持紧凑，避免每个事件都使用厚重面板。
- 颜色只表达语义：青色表示品牌与主要动作，绿色表示成功，黄色表示审批或警告，红色表示失败，灰色表示次要信息。
- 符号和文字共同表达状态，不能只依赖颜色。
- `--no-color`、print 模式和 RPC 模式继续可用；本次只美化 interactive 模式。
- 继续使用现有 Rich 和 prompt_toolkit，不增加 Textual 等大型界面依赖。

## 界面结构

### 启动区

启动界面由三部分组成：

1. 一行简洁品牌标题：`Codepilot`、版本号和一句短描述。
2. 两行会话摘要：当前模型、工作目录、权限模式和短会话 ID。
3. 一行弱提示：`/help`、`Ctrl+C`、多行输入快捷键。

启动区不再使用四行表格式大面板。工作目录使用相对友好的缩略显示，过长时保留尾部；权限模式使用稳定的可读标签。

### 输入区

- 主提示符由 `> ` 改为更明确的 `› `。
- prompt_toolkit 底部工具栏显示模型、权限和快捷键。
- 底栏采用低对比度，不与回答正文争夺注意力。
- 无 prompt_toolkit 时，Rich 和纯文本回退使用相同的 `› ` 语义。

### 助手输出

- 助手正文保持自然流式输出，不套面板。
- 新一轮回答前只保留必要空行，减少界面跳动。
- verbose 信息继续显示，但统一为弱化样式。

### 工具活动

工具调用使用两级结构：

```text
◆ read  src/codepilot/core/agent_loop.py
  └ done  614ms
```

- 首行显示动作和目标，动作用统一的人类可读标签。
- 成功、失败和取消结果显示在缩进的第二行。
- 并发工具仍按 `toolCallId` 独立计时。
- 目标路径、命令和搜索模式继续截断，避免撑满终端。
- 详细工具结果不默认展开，保持 coding agent 的过程可见但不喧宾夺主。

### 警告、审批与错误

- 普通警告使用单行强调，不使用大面板。
- 审批使用细边框面板，因为它需要用户立即决策。
- 错误使用细边框面板，标题显示错误类别，正文显示可操作信息。
- Provider 原始响应保留，但作为次要详情显示。

### 命令与会话反馈

- `/` 命令结果继续由 Runtime 生成，Renderer 负责统一颜色和间距。
- 会话切换、取消、退出等反馈改为一致的状态行，而不是散落的 Rich markup 字符串。
- 不修改命令协议和返回结构。

## 代码边界

### `renderer.py`

负责颜色主题、启动区、工具状态、错误/审批面板以及通用状态消息。允许增加少量私有格式化辅助函数，避免把视觉规则散落在 runner 中。

### `shell.py`

负责输入提示符、补全弹窗和底部工具栏样式。底栏内容由调用方传入，Shell 不读取 Runtime 状态。

### `runner.py`

负责把当前会话状态转换为输入区需要的模型、权限等文字，并调用 Renderer 的状态输出方法。Runner 不直接拼接 Rich markup。

## 兼容性

- Rich 模式获得完整视觉效果。
- `--no-color` 使用等价的纯文本符号和层级。
- print 模式仍只输出适合管道处理的模型正文。
- RPC 模式严格保持 JSONL，不增加任何人类界面输出。
- Windows Terminal、PowerShell、VS Code 终端均使用常见 Unicode 符号；若终端不支持颜色，文字仍能表达状态。

## 测试与验收

- 为启动摘要、工具开始/结束、审批、错误和状态消息补充纯文本快照式断言。
- 为 Shell 提示符和底部工具栏构造函数补充单元测试。
- 保留现有 CLI、Runtime、RPC 测试。
- 运行完整 pytest。
- 用固定的模拟事件生成 Rich 和纯文本终端预览，人工检查宽终端与窄终端下的层级、截断和间距。

## 非目标

- 不实现全屏 TUI、可滚动区域、鼠标交互或复杂布局管理。
- 不新增图片粘贴、命令弹窗、模型选择弹窗等功能。
- 不修改工具执行、权限判定、上下文治理或 Session 数据模型。
- 不复制 Claude Code 或 Codex 的品牌标识和精确配色。
